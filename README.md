# 🐺 ДИКИЙ ИНВЕСТОР v0.1

ZSS-сканер для агрессивной торговли. Третий брат экосистемы: 🌳 KG → 💎 ЗИ → 🐺 ДИ.

## Философия
1. ЗНАЙ РИСК — никогда не входи без стопа (правило 2% — в коде).
2. ЖДИ СИГНАЛ — ZSS ≥ 2.0, не «мне кажется».
3. УПРАВЛЯЙ РАЗМЕРОМ — максимум 2% банка на сделку.
4. ВЕДИ ДНЕВНИК — каждая охота в журнале.
5. ТРОФЕИ ВАЖНЕЕ ПОБЕД — ошибки учат больше.
6. РУЛЬ У ТЕБЯ — приложение показывает, ты решаешь.

## Запуск локально
1. Распакуй ZIP.
2. В папке: `npm install`
3. `npm run dev` → http://localhost:5173/wild-investor/

## Деплой на GitHub Pages
1. Создай репозиторий `wild-investor` (sibpack54-cmd или zimatoken).
2. В папке проекта:
   ```
   git init
   git add .
   git commit -m "v0.1"
   git branch -M main
   git remote add origin https://github.com/USER/wild-investor.git
   git push -u origin main
   ```
3. `npm run build`, затем деплой dist/ в ветку gh-pages (алгоритм «Временная папка» из Саркофага).
4. Сайт: https://USER.github.io/wild-investor/

## Источники данных
- **Авто**: MOEX ISS (публичный, без токена) через CORS-прокси (corsproxy.io → allorigins).
  CORS MOEX привязан к moex.com, прямой запрос из браузера заблокирован — это нормально.
- **Ручной**: вставь 40+ цен закрытия подряд — ZSS посчитается офлайн.

## Мостики
- Общий origin zimatoken.github.io → общий localStorage (как KG ↔ ЗИ, PHASE 16.2).
- Deep links: `?from=kg&amount=5000`.
- Экран 🐺 СТАЯ показывает входящие от KG и ЗИ.
